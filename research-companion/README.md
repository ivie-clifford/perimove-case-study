2A single reflection reason couldn’t capture
several things that went wrong.→

Findings from six usability sessions and a separate product review informed these changes. Implementation was
subsequently checked; the records do not establish that every issue was resolved in user retesting.

What we learned
Research identified uncertainty about
adapting workouts. Testing showed where
PeriMove’s choices and journey needed
clearer explanations. The prototype
implements that daily adaptation loop; its
usefulness over repeated use remains
untested.
Next experiments
1. Professional review of the exercise
content.
2. Repeated-use testing over several days.
3. An earlier explanation of the experience
for first-time visitors.
4. Equivalent mobile and desktop
refinement.
General exercise information. Not medical advice.
