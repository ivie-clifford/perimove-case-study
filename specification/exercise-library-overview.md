# Exercise library: overview

**Status.** The prototype's exercise content is **draft prototype content that no professional has reviewed.** It has not been clinically validated and is not an approved workout program. For this first package the library is described, not reproduced: this file lists its structure, scope and limits, and deliberately leaves out the exercise text (cues, instructions, doses and session scripts).

## What the library is
A small, curated set of home sessions that the rules function selects from. Nothing is generated at runtime and no AI is involved. Every session and every version of an exercise was written for PeriMove by the builder; references were used for technique only.

## Sessions
| Session | Length | What it is | Needs |
|---|---|---|---|
| Strength, 4 movements | 20 min | Squat, hinge, push and pull patterns, each with an easier, base and harder version | Dumbbells, floor space, a stable chair or table |
| Strength, 5 movements | 30 min | The 20-minute movements plus a core exercise with one version | Same as above |
| Standing strength, 3 movements | 15 min | Squat, hinge and press, no pull, so it is not described as full body | Standing space; a chair or table only for some versions |
| Gentle mobility and relaxation | about 10 min | Timed seated blocks with a settling start and a breathing finish; two optional standing exercises when standing space is available | A stable chair |

The library also holds: the explanation and message templates used on screen, the setup-need phrases, reflection prompts, and a small set of general-information tips. The authoring copy held ten tips, seven marked visible when it was written; the copy bundled in the submitted app shows four. Tips without a checked source were held back.

## How versions work
Each slot in a strength session can offer an easier, base and harder version, and some offer an alternative movement. A version is available only if today's setup meets its needs. Where no sourced alternative existed, the slot has one version and the app says so. The user can switch an exercise to another available version, or choose an available alternative movement, on the recommendation screen; during a strength session the level of the current exercise can be changed for its remaining sets. Exercises with one version have no switch, and the gentle session has no levels.

## What the library deliberately leaves out
Movements were included only where a credible technique reference could be found. Where none was found, nothing was added, so the library is small. There is no no-equipment pulling movement, no easier hinge beyond the bodyweight hip hinge, and no non-jumping harder bodyweight squat. Some topics were examined and excluded because the evidence was mixed or not found (for example exercise timing and sleep, and multi-week deload planning).

## What "sourced" means here
A source is a technique reference only (health-service, medical-center and fitness-education pages, paraphrased). It is not clinical validation. Cues, dose, session assembly and modifications were written for PeriMove, and some references match only partly. The two-sets-of-eight-to-twelve dose is a draft basis, not a prescription. Demonstration clips show a movement; they do not validate technique or suitability.

## Two copies of the library, and the source count
There are two versions of the library, and they are not the same size:
- **Authoring copy** (version "0.4-draft", the working master): 26 source entries, 4 sessions, 10 tips.
- **Copy bundled in the submitted app** ("runtime-1", a trimmed version): 11 source entries, the same four sessions, 4 visible tips, plus cues, guided-session text and the demonstration-clip list.

Other project records give 27 and 28 as the source count. Those figures were not traced to a library file; 26 is the number of entries in the authoring copy as of this package, and 11 is the number in the submitted app. The difference is by design (the app copy holds only what the app uses), but whether the 27 and 28 figures counted something else (for example sources dropped or added after a count) is **unresolved**. References used by the app are listed in [credits-and-sources.md](../credits-and-sources.md).
